# 섬과 다리

음악극 〈섬〉 관람 공유회에서 쓰는 모바일 익명 참여 보드예요. 참여자는 로그인 없이 휴대폰으로 자기 섬을 띄웁니다. 섬에는 오늘 돌아보게 된 생각이나 우리 주변의 장벽을 하나 적어요. 그다음 다른 사람의 섬을 읽고, 그 장벽을 낮출 작은 행동 하나로 다리를 놓습니다.

## 어떻게 움직이나요

- 바다는 5×4 격자로 된 20자리예요. 휴대폰 세로 화면에서는 격자를 돌려 4×5로 보여 줘요.
- 다리는 출발 섬과 도착 섬 사이의 최단 경로를 따라 그려져요(E→A→C). 중간에 섬이 있으면 그 섬을 지나가고, 빈자리를 지나가면 징검돌을 띄워요.
- 같은 구간을 지나는 다리가 여러 개면 다리가 굵어지고 숫자가 붙어요.
- 아직 아무 다리도 닿지 않은 섬은 은은하게 빛나요.
- 다른 섬을 누르면 내 캐릭터가 다리 길을 따라 걸어가요. 걷는 중에 화면을 누르면 바로 도착해요.
- 섬을 삭제하면 사라지지 않고 '가라앉은 섬'으로 남아요. 다른 사람이 놓아 준 다리를 지키기 위해서예요.
- 진행자 화면은 주소 뒤에 `?view=host`를 붙이면 돼요. 스마트폰에서도 되고, 바다만 크게 보이며 4초마다 새로 고쳐져요. 위쪽의 **기록 내려받기**와 **전체 리셋** 버튼을 쓸 수 있어요.
- 전체 리셋은 진행자 코드(`server/Code.gs`의 `ADMIN_CODE`)가 있어야 해요. 리셋하기 전의 기록은 시트에 `보관 날짜 시각` 탭으로 복사돼서 남아요.
- 섬은 상하좌우와 대각선으로 붙어 있으면 바로 다리로 이어지고, 떨어져 있으면 가까운 섬을 거쳐 이어져요.

## 배포 방법

1. **Google 스프레드시트**를 새로 만들어요.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 열고, `server/Code.gs`의 내용을 붙여 넣어요.
3. `SHEET_ID`에 스프레드시트 ID(주소의 `/d/`와 `/edit` 사이)를, `EVENT_CODE`에 행사 코드를, `ADMIN_CODE`에 진행자 코드를 적어요. 진행자 코드는 저장소에 올리지 마세요. 예: `'seom1129'`. 비워 두면 코드 검사를 하지 않아요.
4. **배포 → 새 배포 → 웹 앱**을 고르고, 실행 사용자는 '나', 액세스 권한은 '모든 사용자'로 설정해요.
5. 배포가 끝나면 웹 앱 URL이 나와요. 이 주소를 `config.js`의 `BOARD_API`에 넣고, 3번에서 정한 행사 코드를 `EVENT_CODE`에 넣어요.
6. GitHub 저장소 **Settings → Pages**에서 브랜치를 골라 배포해요.

`BOARD_API`를 비워 두면 그 기기에만 저장되는 체험판으로 동작해요.

## 보안에 대해

- 글쓴이 확인은 서버에서 해요. 기기마다 무작위 키를 만들고, 서버는 이 키를 소금(salt)을 쳐서 해시한 값으로만 저장해요. 그래서 다른 사람의 글은 고치거나 지울 수 없어요.
- 웹 앱 주소가 공개 저장소에 들어가면 누구나 그 주소로 요청을 보낼 수 있어요. 행사 코드를 꼭 설정하고, 행사가 끝나면 Apps Script에서 배포를 보관(중지)해 주세요.
- 개인정보는 받지 않아요. 이름도 이메일도 없어요.

## 그림 파일

그림은 모두 `assets/` 폴더에 있고, 목록은 `assets/README.md`에 있어요. `assets/islands/sunk.png`(가라앉은 섬)는 오두막 섬 그림의 색을 빼고 물에 잠기게 만든 거예요.
